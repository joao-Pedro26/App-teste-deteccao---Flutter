C — Menu ⋯ para ações secundárias

CTAs sempre visíveis. Ações de edição escondidas atrás de um botão "mais opções" (⋯) que abre um bottom sheet. Interface mais limpa, mas uma tap a mais.

Minha recomendação: A — é a mais direta para um app de inspeção industrial. As ações de edição são usadas frequentemente, então ocultá-las no ⋯ (C) criaria fricção. FABs (B) ficam ótimos mas exigem mais espaço vertical.

Clique na opção preferida e confirme no terminal.
